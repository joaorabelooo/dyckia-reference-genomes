# Supplementary materials

**[SUPLEMENTAR_GBE.xlsx](SUPLEMENTAR_GBE.xlsx)** contains seven sheets corresponding to Tables S1-S7 cited in the GBE manuscript.

| Sheet | Description |
| --- | --- |
| Table S1 | Sequencing output and flow-cytometry genome-size estimates for *Dyckia consimilis* and *D. rariflora* |
| Table S2 | Repeat classes, counts, masked bases and genomic proportions in representative haplotypes |
| Table S3 | Chromosome-pair collinearity inferred from single-copy orthologs |
| Table S4 | Structural and functional annotation summary for the final longest-isoform gene sets |
| Table S5 | OrthoFinder summary for cleaned longest-isoform proteomes |
| Table S6 | Genome-wide Ka/Ks summaries, candidate high-Ka/Ks calls and codeml evaluation |
| Table S7 | Synonymous-distance summaries and approximate mean- and median-based divergence times |

Table titles and explanatory notes are included in the workbook. It is a curated copy of the author-supplied supplementary workbook, with numerical import errors and a legacy figure reference corrected against existing source outputs. [Curation details](CURATION.md) identify the changes.

## Supplementary figures

No supplementary figures are designated in the current GBE manuscript. The GenomeScope plot called Figure S1 in an older document is Figure 1 in the current manuscript. Main-text figures are not duplicated here.

Genomes, annotations, proteins, coding sequences and reads are accessed through the archival links in the repository's main README. No analysis scripts are included in this deposit.
